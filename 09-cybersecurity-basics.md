# 🔐 Cybersecurity Basics

## 📖 What is Cybersecurity?

**Cybersecurity** is the practice of protecting computers, networks,
devices, accounts, and data from unauthorized access, damage, theft,
or attacks.

Cybersecurity is not only something large companies have to worry about.

It affects everyday technology such as:

- 💻 Computers
- 📱 Smartphones
- 🌐 Networks
- 📧 Email accounts
- ☁️ Cloud accounts
- 🎮 Gaming accounts
- 💳 Online banking
- 🏥 Healthcare systems

Anyone who uses technology can benefit from understanding basic
cybersecurity.

---

## 🖼️ What Does Cybersecurity Look Like?

![Example of cybersecurity](cybersecurity-basics.jpg)

Cybersecurity is not one single program or device.

It can involve many different technologies and practices working
together.

Examples include:

- 🔑 Passwords
- 📲 Multi-factor authentication
- 🛡️ Antivirus protection
- 🔥 Firewalls
- 🔄 Software updates
- 🔐 Encryption
- 💾 Backups
- 👤 User permissions

---

## 💡 Simple Example

I can think of cybersecurity like **protecting a house**. 🏠

A house might have:

- 🔑 Door locks
- 🚪 Strong doors
- 📹 Security cameras
- 🚨 An alarm system
- 💡 Outdoor lights

One security measure alone may not protect against every possible
problem.

Computers are similar.

Using several security measures together can provide better protection.

# 🎯 What Are We Protecting?

Cybersecurity protects more than just computers.

It can also protect **data**.

Data can include:

- 👤 Personal information
- 🔑 Passwords
- 💳 Financial information
- 📧 Emails
- 🖼️ Photos
- 🏥 Medical information
- 📁 Business files

Organizations and individuals may have information that should not be
viewed, changed, or deleted by unauthorized people.

---

# ⚠️ Threats and Vulnerabilities

Two important cybersecurity terms are **threat** and
**vulnerability**.

## 🎯 Threat

A **threat** is something that could potentially cause harm to a system,
network, device, or data.

Examples can include:

- 🦠 Malware
- 🎣 Phishing
- 👤 Attackers
- 🔓 Account theft

## 🕳️ Vulnerability

A **vulnerability** is a weakness that could potentially be used to
cause harm or gain unauthorized access.

Examples might include:

- Outdated software
- Weak passwords
- Incorrect security settings
- Unpatched software

### 💡 Simple Example

Imagine a house with a broken window.

**🕳️ Broken window = Vulnerability**

Someone trying to enter the house through that window could represent a:

**🎯 Threat**

The weakness and the potential danger are related, but they are not the
same thing.

---

# 🦠 Malware

**Malware** means **malicious software**.

It is software designed to perform harmful or unwanted actions.

Different types of malware exist.

Some examples include:

### 🦠 Virus

A virus can attach itself to files or programs and spread when infected
content is executed.

### 🪱 Worm

A worm can spread between systems or across networks without needing to
attach itself to another file in the same way as a traditional virus.

### 🐴 Trojan

A Trojan disguises itself as something legitimate or useful while
containing malicious functionality.

The name comes from the **Trojan Horse** story.

### 🔒 Ransomware

Ransomware is malware that can prevent users from accessing their data
or systems and demand payment.

---

# 🎣 Phishing

**Phishing** is a type of social engineering attack where someone tries
to trick a person into revealing information or performing an unsafe
action.

A phishing message might try to convince someone to:

- 🔑 Enter their password
- 💳 Provide financial information
- 🔗 Click a malicious link
- 📎 Open a dangerous attachment
- 📲 Provide a verification code

---

## 🌎 Real-World Phishing Example

Imagine I receive an email that says:

> "URGENT: Your account will be deleted today! Click here immediately
> to verify your password."

Instead of immediately clicking the link, I should stop and examine the
message.

Possible warning signs could include:

- 🚨 Unusual urgency
- ✍️ Strange wording
- 📧 Suspicious sender address
- 🔗 Unexpected links
- 📎 Unexpected attachments
- 🔑 Requests for sensitive information

Not every unusual email is automatically phishing, but suspicious
messages should be treated carefully.

---

# 🔑 Passwords and Passphrases

Passwords help protect accounts from unauthorized access.

A weak password can make an account easier to compromise.

One approach is using a **passphrase**.

A passphrase uses multiple words or a longer memorable phrase rather
than relying on a short password.

For example, instead of thinking only about complicated characters, a
user can focus on creating a password or passphrase that is:

- 📏 Long
- 🆕 Unique
- 🔐 Difficult for someone else to guess

> ⚠️ I should never place one of my real passwords in a public GitHub
> repository.

---

# 🔁 Password Reuse

Using the same password for many accounts can create additional risk.

If one service is compromised and that password becomes known, an
attacker might try the same credentials on other services.

Using **unique passwords** helps reduce this risk.

---

# 📲 Multi-Factor Authentication

**Multi-factor authentication**, commonly called **MFA**, adds another
layer of authentication.

Instead of relying only on a password, an account may require another
form of verification.

For example:

**🔑 Password**

+

**📱 Verification through another factor**

=

**🔐 Additional account protection**

MFA can make it more difficult for someone to access an account using
only a stolen password.

---

# 🔄 Software Updates

Updates are not only about adding new features.

Updates can also fix **security vulnerabilities**.

This is one reason keeping operating systems and applications updated is
important.

Remember from our previous lessons:

**🪟 Operating System → 🔄 Updates**

and

**📦 Applications → 🔄 Updates**

Cybersecurity gives us another reason those updates matter.

---

# 🔥 Firewalls

A **firewall** helps control network traffic based on security rules.

A firewall can help determine what network communication should be
allowed or blocked.

Firewalls can exist as:

- 💻 Software
- 🛜 Network devices
- 🏢 Larger organizational security systems

At this beginner level, the important idea is:

> 🔥 A firewall helps control network traffic.

---

# 🔐 Encryption

**Encryption** helps protect information by transforming it into a form
that should not be readable without the proper method or key to access
it.

Encryption can help protect:

- 💾 Stored data
- 🌐 Data traveling across networks
- 📱 Devices
- 💬 Communications

### 💡 Simple Example

Imagine putting a message inside a locked box. 📦🔒

Someone may be able to see the box, but they should not be able to read
the message without the correct way to unlock it.

Encryption is much more technical than this example, but the analogy
helps explain the basic purpose.

---

# 💾 Backups

A **backup** is an additional copy of important data.

Backups can help if data is:

- 🗑️ Accidentally deleted
- 💾 Lost because of hardware failure
- 🦠 Damaged by malware
- 🔒 Affected by ransomware
- 🔥 Lost because of physical damage to a device

Cybersecurity is not only about stopping attacks.

It also includes preparing for situations where something goes wrong.

---

# 🛡️ Defense in Depth

Earlier, I compared cybersecurity to protecting a house.

Using several different security protections is sometimes described as
**defense in depth**.

For example:

**🔑 Strong Password**

+

**📲 MFA**

+

**🔄 Updates**

+

**🔥 Firewall**

+

**🛡️ Security Software**

+

**💾 Backups**

Using multiple layers means security does not depend on only one
protection.

## 🛠️ Why Does This Matter in IT?

IT professionals often help protect the systems they manage.

They may need to:

- 🔄 Install security updates
- 👤 Manage user accounts
- 🔑 Reset passwords
- 🦠 Investigate suspicious software
- 🎣 Help users recognize phishing
- 🔥 Configure security settings
- 💾 Maintain backups
- 📊 Review system activity

Even someone who does not work specifically in cybersecurity should
understand basic security practices.
