# 🌐 Networking Basics

## 📖 What is a Computer Network?

A **computer network** is a group of devices that are connected so they
can communicate and share information.

Devices on a network can include:

- 💻 Laptops
- 🖥️ Desktop computers
- 📱 Smartphones
- 🎮 Game consoles
- 🖨️ Printers
- 📺 Smart TVs
- 🛜 Routers
- 🖥️ Servers

Networks can be very small, such as the Wi-Fi network inside a home, or
very large, such as the Internet.

---

## 🖼️ What Does a Network Look Like?

![Example of a computer network](computer-network.jpg)

A basic home network might include several devices connected to a router.

For example:

**💻 Laptop**  
↓  
**🛜 Router**  
↓  
**🌎 Internet**

Other devices, such as phones, game consoles, and smart TVs, may also
connect to the same router.

---

## 💡 Simple Example

I can think of a computer network like a **road system**. 🚗

Different houses and businesses are connected by roads.

The roads allow people to travel from one location to another.

A computer network is similar because it provides a way for information
to travel between devices.

Instead of cars traveling on roads, networks move **data** between
devices.

---

# 📦 What is Data?

**Data** is information that can be stored, processed, or transmitted by
a computer.

Examples include:

- 📝 Text
- 🖼️ Pictures
- 🎵 Audio
- 🎥 Video
- 📧 Email
- 🌐 Website information

When devices communicate over a network, they exchange data.

---

## 🌎 Real-World Example

Imagine I open a web browser and visit a website.

My computer needs to communicate with other devices across a network.

A simplified version might look like:

**💻 My Computer**

↓

**🛜 My Router**

↓

**🌎 Internet**

↓

**🖥️ Web Server**

↓

**🌐 Website**

The server sends information back across the network so the website can
appear on my screen.

A lot more happens behind the scenes, but this is a good beginner way to
understand the process.

---

# 🛜 What is a Router?

A **router** is a networking device that helps direct network traffic
between different networks.

Most people have a router somewhere in their home.

A home router may allow devices such as:

- 📱 Phones
- 💻 Laptops
- 🎮 Consoles
- 📺 Smart TVs

to connect to a home network and access the Internet.

### 💡 Think About It

A router is somewhat like a traffic director. 🚦

It helps information travel toward the correct destination.

---

# 📶 What is Wi-Fi?

**Wi-Fi** allows devices to connect to a network without using a physical
network cable.

For example, my phone may connect to my home network using Wi-Fi.

Wi-Fi is convenient because devices can move around without being
connected directly to the router with a cable.

However:

> 💡 Wi-Fi and the Internet are not the same thing.

Wi-Fi is one way a device can connect to a network.

The Internet is a much larger network that connects networks and devices
around the world.

---

# 🔌 What is Ethernet?

**Ethernet** is commonly used to connect devices to a network using a
physical cable.

An Ethernet cable may connect:

**💻 Computer → 🛜 Router**

or

**🎮 Game Console → 🛜 Router**

A wired Ethernet connection can provide a stable network connection.

---

# 🏠 LAN — Local Area Network

**LAN** stands for:

**Local Area Network**

A LAN connects devices within a relatively small area.

Examples can include:

- 🏠 A home
- 🏫 A school
- 🏢 An office

My home network is an example of a LAN.

---

# 🌎 WAN — Wide Area Network

**WAN** stands for:

**Wide Area Network**

A WAN connects networks across larger geographic areas.

One major example is the:

**🌎 Internet**

At this beginner level, I can remember:

> 🏠 LAN = smaller/local network

> 🌎 WAN = larger network covering greater distances

---

# 🏷️ What is an IP Address?

Devices on a network need ways to identify and communicate with each
other.

An **IP address** is a numerical address used to identify a device or
network interface on an IP network.

One example of an IPv4 address might look like:

`192.168.1.25`

### 💡 Simple Example

An IP address can be compared to a **mailing address**. 📬

If someone wants to deliver a package, they need to know where it should
go.

Network communication also needs addressing information so data can
reach the correct destination.

The comparison is simplified, but it helps explain the basic idea.

---

# 🔢 IPv4

One type of IP address is called **IPv4**.

IPv4 stands for:

**Internet Protocol Version 4**

An IPv4 address usually appears as four numbers separated by periods.

Example:

`192.168.1.10`

Each section can contain a number from **0 through 255**.

---

# 🌐 What is DNS?

**DNS** stands for:

**Domain Name System**

DNS helps computers find the IP addresses associated with domain names.

Humans usually prefer names such as:

`example.com`

instead of trying to remember an IP address.

### 💡 Simple Example

DNS can be compared to a **contact list on a phone**. 📱

I might tap someone's name instead of memorizing their phone number.

DNS provides a similar idea by helping connect human-friendly domain
names with IP addresses.

---

# 🖥️ What is a Server?

A **server** is a computer or software system that provides resources or
services to other devices.

Examples can include:

- 🌐 Web servers
- 📁 File servers
- 📧 Email servers
- 🎮 Game servers

The device requesting a service is often called a **client**.

For example:

**💻 My Browser = Client**

**🖥️ Website Computer = Server**

This relationship is called:

**Client-Server**

---

# ⚙️ What Does Networking Actually Do?

Networking allows devices to communicate and share resources.

Networks can allow users to:

- 🌐 Browse websites
- 📧 Send email
- 🎮 Play online games
- 🎥 Stream videos
- 📁 Share files
- 🖨️ Share printers
- 💬 Send messages
- ☁️ Access cloud services

Many activities I perform every day depend on computer networks.

---

# 🛠️ Why Does Networking Matter in IT?

Network problems are common in IT.

A user might say:

> "My Internet isn't working."

An IT technician may need to determine:

- 📶 Is the device connected to Wi-Fi?
- 🔌 Is the Ethernet cable connected?
- 🛜 Is the router working?
- 🏷️ Does the computer have an IP address?
- 🌐 Can the computer reach other devices?
- 🖥️ Is the problem with the computer or the network?

Understanding basic networking makes troubleshooting these problems
easier.

# 🧪 Beginner Activity: Find My IP Address

For this activity, I will use Windows to view basic information about my
network connection.

---

## 🖥️ Step 1: Open Command Prompt

Click the **Start** button.

Type:

`Command Prompt`

Click **Command Prompt** when it appears.

A black or dark window should open.

This is a **command-line interface**, which I learned about in the
operating systems lesson.

---

## ⌨️ Step 2: Enter a Command

Type:

`ipconfig`

Then press **Enter**.

Windows should display information about the computer's network
connections.

---

## 🔎 Step 3: Find My IPv4 Address

I will look for:

**IPv4 Address**

It may look similar to:

`192.168.x.x`

My actual address may be different.

---

## 🚪 Step 4: Find the Default Gateway

I will also look for:

**Default Gateway**

The default gateway is usually the device that helps my computer reach
other networks.

On many home networks, this is associated with the router.
