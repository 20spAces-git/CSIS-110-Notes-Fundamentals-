# 🧠 RAM (Random Access Memory)

## 📖 What is RAM?

RAM stands for **Random Access Memory**.

RAM is the short-term memory that a computer uses while programs are
running. It temporarily holds information that the computer needs to
access quickly.

A computer uses RAM whenever you are doing things like browsing the
internet, listening to music, writing a document, or playing a game.

## 🖼️ What Does RAM Look Like?

![Example of a RAM module](ram-module.jpg)

The image above shows an example of a RAM module.

The black rectangular pieces are memory chips, while the gold contacts
along the bottom allow the RAM module to connect to the computer's
motherboard.

Different computers can use different types of RAM, so not every RAM
module will look exactly the same.

## 💡 A Simple Way to Think About RAM

Think about RAM like a **desk that you are working at**.

Imagine you are doing homework and have:

- 📕 A textbook
- 📓 A notebook
- 💻 A laptop
- ✏️ Pencils
- 📄 Several worksheets

If your desk is small, you may have trouble keeping everything out at
the same time.

If your desk is bigger, you have more room to work with several things
at once.

RAM works in a similar way.

Having more available RAM gives the computer more room to work with
information from programs that are currently running.

---

## 🌎 Real-World Example

Imagine someone working in an office.

They might have several programs running at the same time:

- 💬 Microsoft Teams
- 📧 Outlook
- 🌐 Google Chrome
- 📊 Microsoft Excel
- 📝 Microsoft Word

All of these programs can use RAM while they are running.

If the computer does not have enough available RAM, the computer may
start to feel slow when the employee tries to use several programs at
once.

---

## ⚙️ What Does RAM Actually Do?

RAM temporarily holds **data and instructions** that the computer may
need to access quickly.

For example, when you open a program, some of the information needed by
that program can be loaded into RAM so the computer can quickly work
with it.

RAM is considered **temporary memory**.

When the computer is turned off or loses power, the information being
stored in RAM is normally lost.

This is one major difference between RAM and storage devices such as
an SSD or hard drive.

---

## 💾 RAM vs. Storage

It can be easy for a beginner to think that RAM and storage are the
same thing, but they have different jobs.

| 🧠 RAM | 💾 Storage |
|---|---|
| Short-term memory | Long-term storage |
| Used while programs are running | Stores programs and files |
| Information is normally lost when power is removed | Information remains after shutdown |
| Helps the computer quickly access active information | Keeps information for future use |

### 💡 Simple Example

If you save a picture on your computer, that picture can be stored on
your SSD.

When you open the picture in a program, RAM can help hold information
that is actively being used while you view or edit it.

---

## 🛠️ Why Does RAM Matter in IT?

Understanding RAM can help with basic computer troubleshooting.

**Troubleshooting** means trying to figure out what is causing a
computer problem and finding a possible solution.

For example, someone might tell an IT support technician:

> "My computer gets really slow when I have a bunch of programs open."

One thing the technician could check is the computer's memory usage.

Windows includes a tool called **Task Manager** that can show how much
RAM is currently being used.

# 🧪 Beginner Activity: Checking Your RAM

For this activity, we are going to use Windows Task Manager to see how
much RAM a computer has and how much is currently being used.

Don't worry if you have never opened Task Manager before. The steps
below will show you how.

---

## 🖥️ Step 1: Open Task Manager

### Method 1 — Keyboard Shortcut

Press these three keys at the same time:

**Ctrl + Shift + Esc**

Task Manager should open.

### Method 2 — Windows Search

If you do not want to use the keyboard shortcut:

1. Click the **Start** button on Windows.
2. Click the search box or begin typing.
3. Type **Task Manager**.
4. Click **Task Manager** when it appears.

---

## 🔎 Step 2: Find Your Memory Information

Once Task Manager is open:

1. Find **Performance**.
2. Click **Performance**.
3. Find **Memory**.
4. Click **Memory**.

You should now see information about your computer's RAM.

Depending on your version of Windows, the screen may show information
such as:

- 🧠 How much RAM your computer has
- 📊 How much memory is currently being used
- 🟢 How much memory is available
- ⚡ Information about your memory speed

Don't worry if you don't understand every number yet.

For this beginner activity, we mainly want to see that the computer has
RAM and that the amount being used can change.

---

## 🧪 Step 3: Watch RAM Being Used

Keep Task Manager open.

Look at how much memory is currently being used.

Now try opening a few programs.

For example:

1. Open your web browser.
2. Open several browser tabs.
3. Open another program such as Microsoft Word or Spotify.
4. Return to Task Manager.
5. Look at **Memory** again.

### 🤔 Think About It

Did the amount of memory being used change?

Why do you think opening more programs could cause the computer to use
more RAM?
