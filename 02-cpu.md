# ⚙️ CPU (Central Processing Unit)

## 📖 What is a CPU?

CPU stands for **Central Processing Unit**.

The CPU is one of the main parts of a computer. Its job is to process
instructions and perform calculations that help the computer complete
tasks.

A simple way to think about the CPU is as one of the computer's main
**workers**.

When you tell the computer to do something, instructions have to be
processed before the computer can complete the task.

---

## 💡 A Simple Way to Think About the CPU

Imagine you are working in a restaurant. 🍽️

A customer gives an order to the server, and that order eventually
reaches the kitchen.

The kitchen follows instructions to prepare the order.

The CPU works in a similar way.

Programs give the computer instructions, and the CPU helps process those
instructions so tasks can be completed.

Of course, a real CPU is much more complicated than a restaurant kitchen,
but the example can help us understand its basic purpose.

---

## 🌎 Real-World Example

Imagine you click the Google Chrome icon on your computer.

To you, it may seem simple:

**Click Chrome → Chrome opens**

But the computer has work to do behind the scenes.

The CPU helps process instructions needed to start Chrome and continues
processing instructions while you use the program.

The CPU is also working when you:

- 🌐 Browse the internet
- 🎮 Play a video game
- 🎵 Listen to music
- 📝 Type a document
- 📊 Use a spreadsheet
- 📁 Open files
- 🖱️ Click buttons inside programs

The CPU is constantly processing instructions while the computer is being
used.

---

## ⚙️ What Does the CPU Actually Do?

The CPU receives and processes instructions.

One basic way of understanding this process is:

**1. Fetch** → Get an instruction.

**2. Decode** → Determine what the instruction means.

**3. Execute** → Perform the instruction.

This process happens extremely quickly and repeatedly while the computer
is running.

You may hear this described as the **fetch-decode-execute cycle**.

Don't worry if that sounds complicated.

For now, the important idea is:

> 💡 The CPU receives instructions, figures out what needs to happen, and
> helps carry out those instructions.

---

## 🧠 How Does the CPU Work With RAM?

The CPU and RAM have different jobs, but they work together.

Remember from the previous lesson that **RAM temporarily holds information
that is actively being used**.

The CPU can access information in RAM while processing instructions.

### 💡 Simple Example

Imagine again that RAM is your **desk**.

The CPU could be compared to the **person sitting at the desk doing the
work**.

The desk holds the materials that are currently needed, while the person
works with those materials.

This is not exactly how a computer works internally, but it is a simple
way to understand why both CPU and RAM are important.

---

## 🛠️ Why Does the CPU Matter in IT?

Understanding CPU usage can help with basic computer troubleshooting.

**CPU usage** tells us how much of the CPU's processing ability is being
used at a particular time.

For example, someone might tell an IT technician:

> "My computer suddenly became really slow."

One thing the technician could check is CPU usage.

If a program is constantly using a very high amount of CPU resources,
that program could be contributing to the computer running slowly.

Windows Task Manager can help us see this.

# 🧪 Beginner Activity: Watching CPU Usage

For this activity, we are going to use **Windows Task Manager** to watch
CPU usage change while the computer performs different tasks.

Don't worry if you have never used Task Manager before.

We'll go through it step by step. 👍

---

## 🖥️ Step 1: Open Task Manager

### Method 1 — Keyboard Shortcut

Press these three keys at the same time:

**Ctrl + Shift + Esc**

Task Manager should open.

### Method 2 — Windows Search

You can also:

1. Click the **Start** button.
2. Click the search box or begin typing.
3. Type **Task Manager**.
4. Click **Task Manager** when it appears.

---

## 🔎 Step 2: Find CPU Information

Once Task Manager is open:

1. Click **Performance**.
2. Find **CPU**.
3. Click **CPU**.

You should see information about your computer's processor.

You may see things such as:

- 📊 CPU usage
- ⚡ CPU speed
- 🧠 Number of cores
- 🔢 Number of logical processors

Don't worry if you don't understand all of these yet.

For this activity, we are mainly interested in the **CPU usage
percentage**.

---

## 📊 What Does the Percentage Mean?

You may see something like:

**CPU: 8%**

or

**CPU: 45%**

The percentage shows how much CPU processing capacity is being used at
that moment.

The number can change very quickly depending on what the computer is
doing.

Seeing the percentage increase does **not automatically mean something
is wrong**.

Computers are supposed to use their CPU when performing tasks.

---

## 🧪 Step 3: Watch the CPU Work

Keep Task Manager open and look at the CPU percentage.

First, watch the percentage while you are not doing much on the computer.

Then:

1. Open your web browser.
2. Open a few websites.
3. Play a video.
4. Open another program.
5. Return to Task Manager.

Watch what happens to the CPU percentage.

---

## 🤔 Think About It

Ask yourself:

**Did CPU usage change when I opened programs?**

**Did it increase when I played a video or loaded a website?**

**Did the percentage stay the same, or did it constantly change?**

The exact numbers will be different on different computers.

That's okay!

The goal is to observe how the CPU responds when the computer performs
different tasks.
