# 🪟 Operating Systems

## 📖 What is an Operating System?

An **operating system**, often shortened to **OS**, is the main software
that helps manage a computer.

The operating system helps the user, applications, and computer hardware
work together.

Without an operating system, using a computer would be much more
difficult.

Some common operating systems include:

- 🪟 Microsoft Windows
- 🍎 macOS
- 🐧 Linux
- 📱 Android
- 📱 iOS

Different devices can use different operating systems.

---

![Example of an operating system](operating-system.jpg)

- 📁 Folders
- 📄 Files
- 🖱️ Menus
- 🪟 Windows
- ⚙️ Settings
- 🔍 Search
- 📌 Taskbars or docks

These are some of the tools the operating system gives us to interact

Not every operating system looks the same.

## 💡 Simple Example

Think of the operating system as a **manager**. 👨‍💼

Imagine a workplace with many different employees and departments.

Someone needs to help organize everything.

The operating system does something similar for a computer.

For example:

- ⚙️ The CPU processes instructions.
- 🧠 RAM holds information currently being used.
- 💾 Storage keeps files and programs.
- ⌨️ Input devices send information to the computer.
- 🖥️ Output devices provide information to the user.

The operating system helps manage how these resources are used.

# 🪟 Microsoft Windows

**Windows** is an operating system developed by Microsoft.

Windows is commonly used on:

- 💻 Laptops
- 🖥️ Desktop computers
- 🏢 Business computers
- 🎮 Gaming computers
- 🏫 School computers

Windows provides tools that allow users to manage files, install
applications, change settings, connect devices, and perform many other
tasks.

Since I currently use Windows, many of the beginner activities in this
repository will use Windows tools.

---

# 🍎 macOS

**macOS** is an operating system developed by Apple.

It is designed for Apple's Mac computers.

Examples include:

- MacBook Air
- MacBook Pro
- iMac
- Mac mini

macOS and Windows look different, but they perform many similar basic
jobs.

Both help users:

- Run applications
- Manage files
- Connect devices
- Access networks
- Change computer settings

---

# 🐧 Linux

**Linux** is another type of operating system.

Linux is especially important in IT and cybersecurity.

Unlike Windows and macOS, Linux comes in many different versions called
**distributions**, often shortened to **distros**.

Examples include:

- Ubuntu
- Fedora
- Debian
- Linux Mint

Different Linux distributions can look and behave differently.

As a beginner, I do not need to know every Linux distribution.

For now, the important thing to understand is that Linux is another
operating system that can manage computer hardware and software.

---

## 🌎 Real-World Example

Imagine I turn on my computer and open a web browser.

Several things happen.

The operating system helps:

1. Start the computer.
2. Recognize connected hardware.
3. Load the desktop.
4. Allow me to open the browser.
5. Give the browser access to resources such as RAM and CPU time.
6. Display the browser on my monitor.
7. Allow my keyboard and mouse to interact with the browser.

I normally do not see all of this happening.

The operating system handles many of these tasks in the background.

# ⚙️ What Does an Operating System Actually Do?

An operating system has several important jobs.

---

## 🧠 Manages Memory

The operating system helps manage the computer's RAM.

Remember:

> 🧠 RAM temporarily holds information that programs are actively using.

When multiple programs are open, the operating system helps manage how
memory is used.

---

## ⚙️ Manages the CPU

Many programs may need to use the CPU.

The operating system helps manage which programs get access to the CPU
and when they get access.

This helps multiple programs run on the computer.

---

## 💾 Manages Files and Storage

The operating system helps organize information stored on the computer.

This includes:

- 📁 Folders
- 📄 Documents
- 🖼️ Pictures
- 🎵 Music
- 🎮 Game files
- ⚙️ Program files

For example, Windows includes **File Explorer**, which allows users to
view and organize files and folders.

---

## 🔌 Manages Hardware

The operating system also helps communicate with hardware.

Examples include:

- ⌨️ Keyboards
- 🖱️ Mice
- 🖨️ Printers
- 🎧 Headphones
- 🌐 Network adapters
- 🎮 Controllers

The operating system often uses special software called a **driver** to
communicate with hardware.

### 🤔 What is a Driver?

A **device driver** is software that helps the operating system
communicate with a specific piece of hardware.

For example, a printer may require a driver so Windows knows how to
communicate with it correctly.

---

## 👤 Manages Users

Operating systems can also manage different user accounts.

A computer might have separate accounts for different people.

User accounts can help control:

- 🔑 Passwords
- 📁 Personal files
- ⚙️ Settings
- 🔒 Permissions

This is especially important on computers used by multiple people.

---

# 🖱️ GUI — Graphical User Interface

Most people interact with their computers using a **GUI**.

GUI stands for:

**Graphical User Interface**

A GUI allows users to interact with the computer using visual elements
such as:

- Icons
- Buttons
- Menus
- Windows
- Folders

For example, clicking the Chrome icon to open a browser is using a GUI.

---

# ⌨️ CLI — Command-Line Interface

Another way to interact with a computer is through a **CLI**.

CLI stands for:

**Command-Line Interface**

Instead of clicking icons and menus, a user types commands.

Windows includes tools such as:

- Command Prompt
- PowerShell

Linux also commonly uses command-line tools.

As a beginner, I do not need to memorize a bunch of commands yet.

The important difference is:

> 🖱️ GUI = interacting mainly through visual elements.

> ⌨️ CLI = interacting mainly by typing commands.

We will work with command-line tools more as I continue learning IT.

---

# 🔄 Operating System Updates

Operating systems receive updates.

Updates can:

- 🐛 Fix software problems
- 🔒 Fix security vulnerabilities
- ⚙️ Improve features
- 🛠️ Improve compatibility
- 🚀 Improve performance

Keeping an operating system updated can be an important part of
maintaining a computer.

---

## 🛠️ Why Does This Matter in IT?

Understanding operating systems is important because IT professionals
work with them constantly.

Someone working in IT may need to:

- 🔍 Troubleshoot Windows problems
- 👤 Manage user accounts
- 💾 Find files
- 🔌 Troubleshoot devices
- 🌐 Configure network settings
- 🔄 Install updates
- 📦 Install or remove software
- 🔒 Change security settings
- ⌨️ Use command-line tools

If a user says:

> "My computer isn't working."

One of the first things an IT technician may need to know is what
operating system the computer is using.
