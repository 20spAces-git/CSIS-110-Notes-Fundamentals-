# 🧩 Motherboard

## 📖 What is a Motherboard?

A **motherboard** is the main circuit board inside a computer.

It provides a place for many of the computer's important components to
connect and communicate with each other.

Some of the components that connect to a motherboard include:

- ⚙️ CPU
- 🧠 RAM
- 💾 Storage
- 🎮 Graphics cards
- 🌐 Network hardware
- 🔌 USB devices and other peripherals

The motherboard does not do the same job as the CPU, RAM, or storage.

Instead, it helps connect these different parts of the computer together.

## 💡 Simple Example

A motherboard can be compared to a **city with roads connecting
different locations**. 🏙️

Imagine:

- ⚙️ The CPU is one building.
- 🧠 RAM is another building.
- 💾 Storage is another location.
- 🛣️ The motherboard provides pathways between them.

The comparison is not perfect, but it helps show how different computer
components need a way to connect and communicate.

---

# ⚙️ CPU Socket

The **CPU socket** is the area of the motherboard where the processor is
installed.

Remember from the CPU lesson:

> ⚙️ The CPU processes instructions and performs calculations that help
> the computer complete tasks.

Different CPUs can require different types of sockets.

This means that **not every CPU works with every motherboard**.

---

# 🧠 RAM Slots

The long slots located near the CPU are usually where RAM is installed.

These are commonly called **RAM slots** or **DIMM slots**.

A RAM module is carefully inserted into one of these slots.

Remember:

> 🧠 RAM temporarily holds information that the computer is actively
> using.

A motherboard may have multiple RAM slots, allowing the computer to use
more than one RAM module.

---

# 💾 Storage Connections

Storage devices also need to communicate with the motherboard.

Different storage devices can use different connections.

Two examples are:

### 🔌 SATA

**SATA** is a type of connection commonly used with some SSDs and HDDs.

### ⚡ M.2

An **M.2 slot** can be used with certain small storage devices,
including many modern SSDs.

I do not need to memorize all of the differences yet.

For now, the important idea is:

> 💡 Storage devices need a compatible way to connect to the computer.

---

# 🎮 Expansion Slots

A motherboard may also contain **expansion slots**.

Expansion slots allow additional hardware to be added to a computer.

One common type is called **PCIe**.

A graphics card is one example of hardware that can use a PCIe slot.

Other expansion cards can add features such as:

- 🌐 Networking
- 🔊 Audio
- 🔌 Additional ports

---

# 🔌 Ports and Connectors

Motherboards also provide connections for many devices.

Depending on the computer, these may include:

- ⌨️ Keyboard
- 🖱️ Mouse
- 🎧 Headphones
- 🌐 Ethernet
- 🔌 USB devices
- 🖥️ Displays

Some connections are located inside the computer.

Others are available on the outside of the computer so that users can
easily connect devices.

---

## 🌎 Real-World Example

Imagine that someone wants to upgrade the RAM in their desktop computer.

They find RAM online and buy it.

But when they try to install it, they discover that it is not compatible
with their computer.

Why?

The motherboard only supports certain types of RAM.

Before buying the upgrade, they should have checked what type of RAM
their motherboard supports.

This is one reason why understanding the motherboard is important.

---

## ⚙️ What Does the Motherboard Actually Do?

The motherboard helps different parts of the computer connect and
communicate.

For example:

When I open a program:

**💾 Storage → 🧠 RAM → ⚙️ CPU**

The program is stored on the computer's storage.

Information needed by the program can be loaded into RAM.

The CPU then processes instructions from the program.

The motherboard provides connections that allow these components to
work together.

---

## 🛠️ Why Does This Matter in IT?

Understanding motherboards can help when:

- 🔧 Building computers
- 🧠 Upgrading RAM
- 💾 Installing storage
- 🎮 Installing a graphics card
- 🔍 Troubleshooting hardware
- 🔌 Checking hardware connections
- ♻️ Replacing computer components

An IT technician may need to determine whether a new component is
compatible with a computer's motherboard before installing it.

# 🧪 Beginner Activity: Find My Motherboard Information

For this activity, I do **not** need to open my computer.

Windows has a built-in tool called **System Information** that can show
information about the computer's hardware.

---

## 🖥️ Step 1: Open System Information

### Method 1

1. Click the **Start** button.
2. Type **System Information**.
3. Click **System Information** when it appears.

### Method 2

Press:

**Windows Key + R**

The **Run** window should appear.

Type:

`msinfo32`

Then press **Enter**.

---

## 🔎 Step 2: Find the Motherboard Information

Make sure **System Summary** is selected on the left side.

Look for:

- **BaseBoard Manufacturer**
- **BaseBoard Product**
- **BaseBoard Version**

### 🤔 What is a BaseBoard?

Windows may use the word **BaseBoard** when displaying information about
the motherboard.

So if I do not see the word "motherboard," I should look for
**BaseBoard** instead.
