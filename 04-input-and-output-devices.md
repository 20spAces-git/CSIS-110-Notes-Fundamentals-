# ⌨️🖥️ Input & Output Devices

## 📖 What Are Input and Output Devices?

Computers need a way to communicate with people and other devices.

Two important groups of computer hardware are:

- ⌨️ **Input devices**
- 🖥️ **Output devices**

An **input device** sends information **into** a computer.

An **output device** receives information **from** a computer and presents
the result to the user.

### 🧠 Easy Way to Remember

Think about the words:

**INput = information goes IN**

**OUTput = information comes OUT**

That simple trick can make it easier to remember the difference. 👍

# ⌨️ What Is an Input Device?

An **input device** is hardware that allows a person or another device to
send information or instructions to a computer.

In other words:

> 💡 Input devices give the computer information.

Common input devices include:

- ⌨️ Keyboard
- 🖱️ Mouse
- 🎤 Microphone
- 📷 Webcam
- 📠 Scanner
- 🎮 Game controller
- 👆 Touchscreen

---

## 💡 Simple Input Example

Think about typing your name into a computer.

You press letters on the keyboard:

**K → A → V → O → N → N → E**

The keyboard sends information about the keys you pressed to the computer.

That makes the keyboard an **input device**.

You are giving information **to** the computer.

---

## 🌎 Real-World Input Example

Imagine an employee working at a hospital, store, school, or office.

They may use:

⌨️ A **keyboard** to enter information.

🖱️ A **mouse** to select items on the screen.

🎤 A **microphone** during a video call.

📷 A **webcam** to send video during a meeting.

📠 A **scanner** to turn a physical document into digital information.

All of these devices are providing some type of **input** to the computer.

---

# 🖥️ What Is an Output Device?

An **output device** is hardware that receives information from a computer
and presents that information in a form that a person can use.

In simpler words:

> 💡 Output devices give information **from the computer to us**.

Common output devices include:

- 🖥️ Monitor
- 🔊 Speakers
- 🎧 Headphones
- 🖨️ Printer
- 📽️ Projector

---

## 💡 Simple Output Example

Imagine watching a YouTube video.

The computer processes the video, but you need devices that allow you to
experience it.

Your:

🖥️ **Monitor** displays the video.

🔊 **Speakers** play the sound.

Both are output devices because the computer is sending information
**out to you**.

---

## 🌎 Real-World Output Example

Imagine an employee creates a report.

The report can be:

🖥️ Displayed on a monitor.

🖨️ Printed using a printer.

📽️ Displayed to a group using a projector.

The computer is providing information through these devices.

---

# 🔄 Can a Device Be BOTH Input and Output?

Yes!

Some devices can perform both jobs.

A great beginner example is a:

# 📱 Touchscreen

A touchscreen can display information, which makes it an:

**Output device 🖥️**

But you can also touch the screen to make selections, which makes it an:

**Input device 👆**

So a touchscreen can perform **both input and output**.

---

## 📱 Simple Touchscreen Example

Think about your smartphone.

When the phone displays a button:

📱 → 👀

The screen is providing **output**.

When you tap the button:

👆 → 📱

You are providing **input**.

The same physical screen is helping information travel in both directions.

---

# ⚙️ What Actually Happens?

Let's use clicking an application as an example.

Imagine you click the icon for a web browser.

### 1️⃣ INPUT

You click the mouse.

**🖱️ Mouse → Computer**

The mouse sends information to the computer.

### 2️⃣ PROCESSING

The computer processes the instruction.

The CPU helps process the instructions needed to respond to your action.

**🖱️ Input → ⚙️ Processing**

### 3️⃣ OUTPUT

The application appears on your monitor.

**⚙️ Processing → 🖥️ Monitor**

The monitor provides the visual result.

Put everything together:

> **🖱️ INPUT → ⚙️ PROCESSING → 🖥️ OUTPUT**

This is a simple way to understand how information can move through a
computer system.

---

# 🧩 What Is a Peripheral?

While learning about input and output devices, you may hear the word:

**Peripheral**

A **peripheral device** is a hardware device that connects to or works
with a computer to provide additional functionality.

Examples can include:

- ⌨️ Keyboard
- 🖱️ Mouse
- 🖨️ Printer
- 🎤 Microphone
- 📷 Webcam
- 🎮 Controller

Don't worry about memorizing every type right now.

For a beginner, the important idea is that many devices we connect to
computers can be described as **peripherals**.

---

# 🛠️ Why Does This Matter in IT?

IT support technicians often troubleshoot problems involving input and
output devices.

For example, a user might say:

> "My keyboard isn't working."

or:

> "I can't hear anything from my speakers."

or:

> "My second monitor isn't showing anything."

An IT technician needs to understand what type of device is having the
problem before troubleshooting it.

They might check things such as:

- 🔌 Is the device connected?
- 🔋 Does the device have power?
- 📶 Is a wireless device connected?
- ⚙️ Does Windows recognize the device?
- 🔊 Is the correct audio output selected?
- 🖥️ Is the correct display selected?

Understanding the basic purpose of the device makes troubleshooting
easier.

# 🔗 Connecting This to Previous Lessons

We're starting to see how different parts of a computer work together.

### ⌨️ Input
Provides information or instructions to the computer.

### ⚙️ CPU
Helps process instructions.

### 🧠 RAM
Temporarily holds information that is actively being used.

### 💾 Storage
Keeps information for long-term use.

### 🖥️ Output
Provides results or information back to the user.

A very simple way to visualize part of this process is:

> **⌨️ INPUT → ⚙️ PROCESSING → 🖥️ OUTPUT**

Computers are much more complicated than this simple diagram, but it
gives beginners a foundation to build on.
