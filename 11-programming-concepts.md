# 💻 Programming Concepts

## 📖 What is Programming?

**Programming** is the process of giving a computer instructions so that
it can perform a task.

Those instructions are written using something called a
**programming language**.

Programming is used to create many of the technologies I use every day.

Examples include:

- 🌐 Websites
- 📱 Mobile apps
- 🎮 Video games
- 🖥️ Computer programs
- 🤖 Automation tools
- 📊 Data tools
- 🔐 Cybersecurity tools

At this beginner level, I do not need to know how to build a complete
program yet.

The important idea is:

> 💡 A programmer creates instructions, and the computer follows those
> instructions to perform a task.

---

## 🖼️ What Does Programming Look Like?

![Example of computer programming](programming-example.jpg)

Programming often involves writing instructions called **code**.

Code can look confusing when seeing it for the first time.

For example:

```python
print("Hello!")
```

This is one line of code written in a programming language called
**Python**.

It tells the computer to display:

```text
Hello!
```

Different programming languages can look different, but they all give
programmers ways to create instructions for computers.

---

## 💡 Simple Example

Programming can be compared to giving someone **step-by-step
instructions**. 📋

Imagine I tell someone:

1. Walk into the kitchen.
2. Open the refrigerator.
3. Get a bottle of water.
4. Close the refrigerator.
5. Bring me the water.

The instructions have a specific order.

If I leave out an important step or give the wrong instruction, the
result might not be what I expected.

Programming works in a similar way.

Computers follow the instructions they are given.

---

## 🌎 Real-World Example

Imagine I use a calculator application to add:

`25 + 10`

I press the buttons and the calculator displays:

`35`

Behind the scenes, software contains programming instructions that tell
the computer how to process the numbers and display the answer.

Programming helps turn what I want the computer to do into instructions
the computer can process.

---

# 🗣️ Programming Languages

A **programming language** gives programmers a structured way to write
instructions for computers.

There are many programming languages.

Examples include:

- 🐍 Python
- ☕ Java
- 🟨 JavaScript
- ➕ C++
- #️⃣ C#

Different programming languages can be used for different types of
projects.

For example, programming can be used for:

- Websites
- Applications
- Games
- Automation
- Data analysis
- Cybersecurity

I do not need to learn every programming language.

Just like people choose different tools for different jobs, programmers
can choose languages based on what they are trying to create.

---

# 🧾 What is Code?

**Code** is the set of instructions written using a programming
language.

For example:

```python
print("I am learning programming!")
```

The computer follows the instruction and displays:

```text
I am learning programming!
```

A large application can contain many lines of code working together.

---

# 📦 Variables

Programs often need to temporarily keep track of information.

A **variable** is a named place used to store a value that a program can
use.

For example:

```python
name = "Alex"
```

In this example:

`name`

is the variable.

`Alex`

is the value being stored.

### 💡 Simple Example

I can think of a variable like a **labeled box**. 📦

The label tells me what information I expect to find inside.

For example:

**📦 Box Label:** Name

**Inside:** Alex

A program can use the information stored in that variable later.

---

# 🔢 Different Types of Data

Programs work with different kinds of information.

These are often called **data types**.

At this beginner level, I will focus on a few basic examples.

### 🔤 Text

Text is often called a **string**.

Example:

```text
"Hello"
```

### 🔢 Whole Numbers

A whole number can be called an **integer**.

Example:

```text
25
```

### ✅ True or False

Some programming situations use values that represent:

```text
True
```

or

```text
False
```

These are called **Boolean values**.

I do not need to memorize every data type yet.

The important idea is:

> 💡 Programs can work with different types of information.

---

# 🧠 Programs Can Make Decisions

Programs do not always perform the exact same action every time.

Sometimes they need to make a decision based on information.

Imagine a program checking someone's age.

The basic idea could be:

```text
IF age is 18 or older
    Display "Adult"
ELSE
    Display "Minor"
```

This is an example of **programming logic**.

The computer checks a condition and performs an action based on the
result.

---

# 🔁 Programs Can Repeat Tasks

Computers are useful for performing repetitive tasks.

A programmer can create instructions that repeat.

This is commonly done using something called a **loop**.

### 💡 Simple Example

Imagine I need the computer to display:

`Hello`

five times.

Instead of manually writing the same instruction five times, I could use
programming logic that tells the computer to repeat the task.

Loops become especially useful when something needs to happen many
times.

---

# 🐛 What is a Bug?

Programs do not always work correctly the first time.

A **bug** is an error or problem that causes software to behave
incorrectly or unexpectedly.

A bug might cause a program to:

- ❌ Give the wrong answer
- 💥 Crash
- 🐌 Run poorly
- 🚫 Fail to perform a task

---

# 🔍 What is Debugging?

**Debugging** is the process of finding and fixing problems in code.

For example, imagine I accidentally write:

```python
print("Helo!")
```

The program may still run, but I accidentally misspelled the word.

I would need to find the mistake and correct it.

Programmers often spend time testing their programs and fixing problems.

---

## ⚙️ What Does Programming Actually Do?

Programming allows people to create instructions that computers can
follow.

Those instructions can tell computers to:

- 🧮 Perform calculations
- 📊 Process data
- 📁 Work with files
- 🌐 Communicate across networks
- 🎮 Run games
- 📱 Run applications
- 🤖 Automate repetitive tasks
- 🔍 Search information

Programming is one of the ways software is created.

Remember from Lesson 7:

> 📦 Software contains instructions that tell computers what to do.

Programming is how many of those instructions are created.

---

## 🤖 Programming and Automation

One useful purpose of programming is **automation**.

Automation means using technology to perform tasks with less manual
work.

For example, a program could automatically:

- 📁 Organize files
- 📊 Process information
- 🔎 Search data
- 💾 Create backups
- 📧 Send notifications

Instead of manually performing the same task repeatedly, a computer can
be instructed to perform it automatically.

## 🛠️ Why Does This Matter in IT?

Not every IT professional is a programmer.

However, understanding basic programming concepts can still be useful in
IT.

Programming can help develop skills such as:

- 🧠 Logical thinking
- 📋 Following processes
- 🔍 Troubleshooting
- 🐛 Finding errors
- 🤖 Automating tasks
- 📊 Working with data

IT professionals may also encounter scripts and commands that automate

understand later.
